INSTALL
-------
Windows
  Run BnB-{VERSION}-windows-setup.exe. It installs for you alone, without administrator rights, and puts the
  game in the Start menu.
  Windows may say "Windows protected your PC", because the alpha is not code-signed. Click "More info", then
  "Run anyway".
  Would rather not install anything? Unpack BnB-{VERSION}-windows-portable.zip anywhere and start
  bureaucrats-and-broomsticks.exe.

Linux (x86_64)
  Make BnB-{VERSION}-linux-x86_64.AppImage executable (chmod +x, or right-click > Properties > "Allow executing"),
  then start it.
  If the AppImage does not start, unpack BnB-{VERSION}-linux-x86_64.tar.gz and run bureaucrats-and-broomsticks.x86_64.

UPDATING
  Install the new version over the old one. Your runs, saves and settings are kept: they are not stored in the
  game folder.

WHAT THE GAME SENDS HOME
  Every run you finish or give up is sent to us: the seed, every choice you made, the name you entered, a random
  player ID and, if you filled it in, your Form B-7 rating and remark. We use it to balance the game.
  Found a bug? Press "Report a bug" on the title screen or in the Esc menu. Your report goes straight to us,
  together with your operating system, language and window size, so we can reproduce it.

YOUR SAVES
  Windows:  %APPDATA%\Godot\app_userdata\Bureaucrats & Broomsticks
  Linux:    ~/.local/share/godot/app_userdata/Bureaucrats & Broomsticks

INSTALLATION
------------
Windows
  BnB-{VERSION}-windows-setup.exe starten. Das Spiel wird nur für dich installiert, ohne Administratorrechte,
  und erscheint im Startmenü.
  Windows meldet eventuell "Der Computer wurde durch Windows geschützt", weil die Alpha nicht signiert ist.
  Klicke auf "Weitere Informationen" und dann auf "Trotzdem ausführen".
  Lieber ohne Installation? BnB-{VERSION}-windows-portable.zip irgendwo entpacken und
  bureaucrats-and-broomsticks.exe starten.

Linux (x86_64)
  BnB-{VERSION}-linux-x86_64.AppImage ausführbar machen (chmod +x, oder Rechtsklick > Eigenschaften >
  "Als Programm ausführen") und starten.
  Startet das AppImage nicht, BnB-{VERSION}-linux-x86_64.tar.gz entpacken und bureaucrats-and-broomsticks.x86_64
  starten.

UPDATE
  Die neue Version einfach über die alte installieren. Runs, Spielstände und Einstellungen bleiben erhalten,
  denn sie liegen nicht im Spielordner.

WAS DAS SPIEL ÜBERTRÄGT
  Jeder beendete oder abgebrochene Run wird an uns geschickt: der Seed, jede deiner Entscheidungen, der
  eingegebene Name, eine zufällige Spieler-ID und, falls ausgefüllt, deine Bewertung und Bemerkung im
  Formular B-7. Damit balancieren wir das Spiel.
  Einen Fehler gefunden? Klicke auf "Report a bug" im Titelbildschirm oder im Esc-Menü. Der Bericht kommt direkt
  bei uns an, zusammen mit Betriebssystem, Sprache und Fenstergröße, damit wir den Fehler nachstellen können.
